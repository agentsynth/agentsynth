AgentSynth generates synthetic tool-use trajectories, checks them against the world's end state, and turns them into RL rewards, benchmarks, and a live leaderboard.

Get started See the live leaderboard

Most synthetic agent data is graded on vibes. AgentSynth grades on outcomes: a trajectory passes only when the database, API, or sandbox actually ends up in the goal state — so the reward can't be farmed by a model that just says it did the work.

Get started

# offline mock by default — no API keys needed
pip install agentsynth-ai
from agentsynth import AgentTrajectoryGenerator, TrajectoryEvaluator

gen = AgentTrajectoryGenerator()
traj = gen.generate("Refund order 7 in the orders database, then confirm")
score = TrajectoryEvaluator().evaluate(traj)

Then put a model on the board — the pack downloads itself, nothing to clone (--policy mypkg.module:fn benches your own agent loop instead):

agentsynth bench --pack core_v1 --model <your-model> --submit
