# AgentSynth — example datasets

These files come from running the `agentsynth` package in deterministic offline
mock mode (`AGENTSYNTH_FORCE_MOCK=1`). There are 12 synthetic agent trajectories,
generated from six seed queries across a few domains (weather + math, SQL data
analysis, file QA, code-based data analysis, a coding task). They were generated
with `vary_modes=True`, so the batch splits evenly across the three trajectory
modes: 4 `single_agent`, 4 `multi_agent`, 4 `code_execution`.

Re-running the generator with the same seed reproduces these exact trajectories.

## Files

| File | What it is |
| --- | --- |
| [`sample_trajectories.jsonl`](sample_trajectories.jsonl) | The canonical dataset, and the one the other three are derived from. One JSON object per line, one line per trajectory. Round-trips back into `Trajectory` objects. |
| [`sample_sharegpt.json`](sample_sharegpt.json) | The same 12 trajectories in ShareGPT chat format (`{"conversations": [...], "tools": [...]}`), pretty-printed. Works with Axolotl / Unsloth chat-SFT recipes. |
| [`sample_adp.json`](sample_adp.json) | The same trajectories as ADP (Agent Data Protocol, `adp/0.1`) records, which keep thoughts, tool calls, observations, and code execution as typed steps. Pretty-printed. |
| [`sample_eval.jsonl`](sample_eval.jsonl) | LLM-as-Judge verdicts: `EvalResult.flat()` for each trajectory, one JSON object per line. Join back to a trajectory on `trajectory_id`. |

## JSONL schema (`sample_trajectories.jsonl`)

Each line is one JSON object with these fields:

| Field | Type | Notes |
| --- | --- | --- |
| `id` | string | Stable 12-char trajectory id. |
| `query` | string | The user task the agent was asked to solve. |
| `mode` | string | One of `single_agent`, `multi_agent`, `code_execution`. |
| `domain` | string \| null | Optional domain tag (e.g. `weather_math`, `data_analysis_sql`). |
| `messages` | list | OpenAI-style `messages` rendering (user / assistant / tool roles, assistant `tool_calls` preserved). Derived from `steps`, regenerated on load. |
| `tools` | list | The tool catalog attached to the trajectory (`name`, `description`, JSON-Schema `parameters`). |
| `steps` | list | The raw typed steps. Each has a `step_type` (`thought`, `plan`, `tool_call`, `observation`, `code_execution`, `critique`, `final_answer`) plus only the fields relevant to that type (`thought`, `tool_name`, `tool_args`, `observation`, `code`, `code_output`, `content`, `agent`). |
| `final_answer` | string | The agent's final answer. |
| `success` | bool | Whether the trajectory is considered successful. |
| `generator_model` | string | `mock` here (offline deterministic generation). |
| `metadata` | object | Free-form generation metadata (`mode`, `n_steps`, `index`, …). |

### Eval schema (`sample_eval.jsonl`)

Each line is the flattened `EvalResult`:

```
trajectory_id, overall, passed, judge_model,
task_completion, tool_correctness, faithfulness,
reasoning_coherence, efficiency, safety
```

`overall` and every rubric dimension are floats in `[0, 1]`; `passed` is
`overall >= pass_threshold` (default `0.6`).

## How to load

The JSONL round-trips back into `Trajectory` objects:

```python
from agentsynth import load_jsonl

trajectories = load_jsonl("examples/sample_trajectories.jsonl")
print(len(trajectories), "trajectories")

t = trajectories[0]
print(t.id, t.mode, t.domain)
print("tools used:", t.tool_names_used())
print("final answer:", t.final_answer)
```

The eval rows are plain JSON. Load them with the stdlib and join on
`trajectory_id`:

```python
import json

with open("examples/sample_eval.jsonl") as fh:
    evals = [json.loads(line) for line in fh if line.strip()]

by_id = {e["trajectory_id"]: e for e in evals}
print(by_id[trajectories[0].id]["overall"])
```

The ShareGPT and ADP files are ordinary JSON arrays:

```python
import json

sharegpt = json.load(open("examples/sample_sharegpt.json"))
adp = json.load(open("examples/sample_adp.json"))
```

## Regenerating

These files were generated by running the package directly in mock mode. The
minimal recipe:

```python
import os
os.environ["AGENTSYNTH_FORCE_MOCK"] = "1"

from agentsynth import AgentTrajectoryGenerator, TrajectoryEvaluator, to_jsonl, to_sharegpt, to_adp

queries = [
    "What's the weather in Tokyo and what's an 18% tip on a $54 dinner bill?",
    "Analyze last quarter's sales from the analytics database with a SQL query and email a summary to the team.",
    "Read report.csv and tell me the total revenue and which region performed best.",
    "Write and run Python to compute the mean and standard deviation of 12, 19, 7, 22, 31, 44.",
    "Find the 10th Fibonacci number and briefly explain the recurrence.",
    "What's the weather in Reykjavik right now, and should I pack a warm coat?",
]

gen = AgentTrajectoryGenerator(seed=7)
trajectories = gen.generate_batch(queries, num_trajectories=12, vary_modes=True)

to_jsonl(trajectories, "sample_trajectories.jsonl")
to_sharegpt(trajectories, "sample_sharegpt.json")
to_adp(trajectories, "sample_adp.json")

results = TrajectoryEvaluator().evaluate_batch(trajectories)
# sample_eval.jsonl is one EvalResult.flat() per line.
```
