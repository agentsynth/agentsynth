# AgentSynth Tools

Synthetic, verified multi-step agent trajectories for fine-tuning agentic LLMs —
tool use, grounded code execution, and multi-agent collaboration. Generated and scored
with [AgentSynth](https://github.com/agentsynth/agentsynth).

- **Trajectories:** [N]
- **Modes:** single-agent, multi-agent, code-execution
- **Generator:** [model id, or "deterministic mock"]
- **Judge:** [model id] · **pass@1:** [X]% at threshold 0.6
- **Built with:** AgentSynth v[0.1.x] · reproducible from the recipe below

## What's in it

Each row is one trajectory. The canonical JSONL fields:

| Field | Type | Notes |
| --- | --- | --- |
| `id` | string | Stable trajectory id |
| `query` | string | The user task |
| `mode` | string | `single_agent` / `multi_agent` / `code_execution` |
| `domain` | string \| null | Domain tag |
| `messages` | list | OpenAI-style messages (user / assistant / tool), tool calls preserved |
| `tools` | list | The tool catalog (JSON-Schema parameters) |
| `steps` | list | Typed steps: thought, tool_call, observation, code_execution, critique, final_answer |
| `final_answer` | string | The agent's answer |
| `success` | bool | |
| `generator_model` | string | |
| `metadata` | object | |

A ShareGPT-formatted copy is also provided for chat-SFT trainers.

## How it was made

Trajectories were generated by AgentSynth and scored by an LLM-as-Judge over a
six-dimension rubric (task completion, tool correctness, faithfulness, reasoning
coherence, efficiency, safety). Where an execution environment was used, observations
are real output — `sql_query` ran against SQLite and `python` ran in an isolated
subprocess — not model guesses. Only trajectories above the pass threshold are included.

## Usage

```python
from datasets import load_dataset

ds = load_dataset("agentsynth/agentsynth-tools", split="train")
print(ds[0]["query"], ds[0]["mode"])
```

Or with the library, which round-trips the JSONL back into objects:

```python
from agentsynth import load_jsonl
trajectories = load_jsonl("train.jsonl")
```

## Reproduce it

```python
from agentsynth import Recipe, run_recipe

run_recipe(Recipe(
    domains=["data_analysis", "coding", "weather_math"],
    num_trajectories=[N],
    vary_modes=True,
    environment="sql+python",
    export_format="jsonl",
    export_path="train.jsonl",
))
```

## Intended use

Fine-tuning and evaluating agentic / tool-using LLMs (SFT; preference data where a
DPO split is provided). Compatible with TRL, Unsloth, and Axolotl.

## Limitations and biases

- **This is synthetic data.** It reflects the generator and judge models and the seed
  tasks, not real user behavior. Validate on your own benchmark before relying on it.
- Mock-generated rows are deterministic and templated; LLM-generated rows vary with the
  model used. The `generator_model` field tells you which.
- The judge is imperfect; `pass@1` is a quality signal, not a guarantee.
- English-only at present.
